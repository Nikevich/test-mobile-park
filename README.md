# Тестовое задание
### Запуск
Перед запуском необходимы 3 виртуальные машины со статическим IP. Эти адреса требуется определить в instances, расположенных в `prod/hosts.yml`. Также требуется предварительно установить Ansible на хост-контроллер. Далее команда для развертывания серверов:
```
ansible-playbook playbooks/main.yml
```
Эта команда запустит главный плейбук, в котором лежат ссылки на все последующие прейбуки.
### Описание плейбуков
Помимо главного имеются следующие плейбуки:
- *set-properties.yml* - настраивает hostname, запрещает вход руту и вход по паролю по ssh
- *create-users.yml* - создает необходимых пользователей
- *install-tools.yml* - устанавливает приложения для администрирования и + Docker
- *docker-create.yml* - разворачивает сервисы при помощи Docker Swarm
